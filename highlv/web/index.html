Lệnh vận hành

Xếp hai chân đúng HOME bằng tay trước khi bấm Set homing; nút chỉ chụp mốc, không làm chân chuyển động. Calib IMU cần motor OFF và giữ robot hoàn toàn yên; ESP lấy ít nhất 500 mẫu rồi báo kết quả. Cả hai lệnh không tự ARM.

ARM chỉ là yêu cầu. LF và ESP32 vẫn kiểm tra liên kết, cảm biến, tư thế home và trạng thái driver. E-STOP qua mạng không thay thế nút dừng cứng.

Token lưu trong trình duyệt này. Lấy token bằng SSH từ file cấu hình web trên LF.

LF → ESP → Motor

Số đo độc lập với ACK. Chu kỳ gồm startup/poll và xử lý OFF khi lỗi; I/O là từng giao dịch. Kết quả thực thi vẫn cần cả hai bus.
